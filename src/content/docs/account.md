# 账号与同步

## 登录

Prime Work 使用飞书账号登录。点击登录按钮，在飞书中确认授权，完成后会回到应用。

登录状态保存在本机；退出登录不会删除本机已有的插件、主机与本地配置。

## 云端同步

登录后以下数据随账号同步：

- 菜单、分类与排序
- 插件启用状态
- 站点导航
- SSH 主机配置
- AI 会话

换设备登录后会自动恢复；云端暂时不可用时保留本地选择，恢复后继续同步。

## 本地数据与加密

- SSH 密码与私钥使用加密存储，接口不返回明文。
- 模型 API Key 由服务端读取加密配置，不写入浏览器 localStorage。
- 插件配置中的 secrets 字段加密保存。
- 插件源码与缓存保留在本机，不会随账号上传。

## 用户信息

右上角头像进入用户信息页，可以查看：

- 当前账号
- 当前版本与更新状态
- 最近版本的更新日志
- 退出登录

## 退出登录

在用户信息页点击「退出登录」。退出只清除本机登录态，不删除云端数据；下次登录会重新同步。
