# AI 助手

AI 助手以右侧面板形式工作，支持 Chat 与 Agent 两种模式。

## 配置模型

打开 **设置 → 模型配置**，添加模型提供方与 API Key，保存后测试连通性。模型路由立即生效，不需要重启。

支持多个模型切换、批量连通性测试，以及 DeepSeek 余额查询。

## Chat 模式

适合问答、写作、代码解释与资料整理。回复以流式返回，支持停止生成、重新生成与回复分支切换。

## Agent 模式

适合多步任务：读取文件、运行命令、调用技能、维护计划，并在执行过程中展示工具调用与进度。

Agent 在终端执行命令前会显示命令摘要并请求确认；未确认不会执行。

## 技能

输入 `/` 选择技能，或让模型根据任务自动判断。技能中心可以启用/停用技能，并提示依赖与互斥关系。插件也可以在自己的清单里声明命令与技能，启用后出现在「/」面板。

## 会话管理

- 多会话列表，可重命名、归档与搜索
- 会话历史随账号同步
- 上下文压缩与占用指示
- 消息操作栏与时间显示

## 上下文与附件

支持图片、文档附件、联网搜索与来源引用。深度思考内容会折叠显示，回答可以继续追问。

## 安全

- 命令执行需要确认
- 插件调用受权限限制
- API Key 不写入浏览器 localStorage
- 模型请求统一由服务端读取加密配置
