# 常见问题

## 数据存在哪里？

桌面端保存在本机应用数据目录；登录后菜单、插件状态、主机与 AI 会话同步到云端。凭据使用加密存储，接口不返回明文。

## 浏览器里能用吗？

可以预览界面、查看文档与版本记录；SSH 终端、SFTP、端口转发和命令执行需要桌面客户端。

## 支持 Windows 吗？

支持 Windows 10/11 x64 与 macOS（Apple Silicon）。不同版本的具体能力以版本记录为准。

## 离线能用吗？

本机已安装的插件、SSH 主机与本地配置可以离线使用；登录、云端同步与模型调用需要网络。

## 插件安全吗？

外部插件运行在沙箱 iframe 中，只能调用已声明的权限。`pwb.fetch` 受域名白名单限制，`desktop` 权限不对插件开放。

## Agent 会自动执行命令吗？

不会。Agent 在终端执行命令前会显示命令摘要并请求确认；未确认不会执行。

## 如何安装外部插件？

设置 → 插件中心可以从开发目录或 zip 包导入，也可以从插件市场安装。安装完成后在插件中心启用。

## 更新失败怎么办？

确认网络与磁盘空间；桌面端可以在设置 → 关于中重新检查更新。若安装后无法启动，保留应用数据目录并联系维护者。
