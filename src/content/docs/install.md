# 安装与更新

## 系统要求

| 平台 | 构建 |
| --- | --- |
| macOS | Apple Silicon（arm64） |
| Windows | Windows 10 / 11 x64 |

## 安装

1. 从发布渠道获取对应平台的安装包。
2. macOS：打开 `.dmg`，把 Prime Work 拖入「应用程序」。
3. Windows：运行 `.exe` 安装程序，按提示完成安装。
4. 首次启动：
   - macOS 若提示无法验证开发者，在「系统设置 → 隐私与安全性」中允许。
   - Windows 若出现 SmartScreen 提示，选择「更多信息 → 仍要运行」。

> 下载通道与可用构建以版本页的说明为准。

## 自动更新

桌面端默认在启动时检查更新。打开 **设置 → 关于** 可以：

- 查看当前版本
- 手动检查更新
- 开关自动更新
- 下载完成后立即重启安装

网页端只展示当前版本，更新由桌面端完成。

## 数据位置

| 平台 | 路径 |
| --- | --- |
| macOS | `~/Library/Application Support/Prime Work/` |
| Windows | `%APPDATA%\Prime Work\` |

登录后，菜单、插件状态、主机与 AI 会话同步到云端；插件包、缓存与日志保留在本机。

## 卸载

- macOS：从「应用程序」删除 Prime Work。
- Windows：在「设置 → 应用」中卸载。
- 如需彻底清理，可在退出应用后删除上面的数据目录。
