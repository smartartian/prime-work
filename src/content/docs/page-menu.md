# 页面菜单

页面菜单（`page-menu`）集中收纳常用外链页面，点击后用系统浏览器打开。

## 安装

- **市场安装**：设置 → 插件市场 → 页面菜单 → 安装。
- **离线导入**：设置 → 插件中心 → 导入插件包，选择 zip。
- 客户端要求以插件市场提示为准。
- 首次安装后，在插件中心点击「配置菜单」，选择分类并创建左侧导航入口。

## 使用

1. 左侧分类栏按分类筛选，右侧显示链接列表。
2. 点击「新增链接」，填写名称、网址与分类。
3. 点击链接右侧「打开」，用系统默认浏览器打开。
4. 点击「×」删除链接；分类为空时不再展示。

## 数据与权限

- 链接与分类保存在插件私有存储中，与其他插件隔离。
- 数据只保存在本机，不随云端配置同步。
- 权限：`storage`、`network`。
- 不申请 `filesystem`、`ssh`、`ai`、`desktop`。
- 受外部插件沙箱限制，页面菜单**不支持在工作台内嵌渲染网页**，所有链接都会用系统浏览器打开。

## 更新与卸载

- 市场更新或导入同名 zip 会覆盖安装，链接数据保留。
- 停用插件后入口不可用，数据保留。
- 卸载会删除插件目录，插件配置与私有存储默认保留。

## 常见问题

**安装按钮是灰色的？**

浏览器预览模式不支持远程安装；从市场安装还需要登录账号。也可以改用离线导入。

**安装后左侧没有入口？**

先在插件中心点击「配置菜单」，选择分类并创建导航项，左侧才会出现入口。

**可以在工作台内打开网页吗？**

外部插件版本不支持内嵌渲染，所有链接都会用系统浏览器打开。需要内嵌能力时请关注后续版本。
