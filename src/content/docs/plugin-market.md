# 插件市场

插件市场用于安装、更新和管理外部插件。当前上架的插件以市场页面显示为准，包括 SSH 终端、站点导航与页面菜单。

## 从市场安装

1. 登录云端账号。
2. 打开 **设置 → 插件市场**。
3. 选择插件并点击「安装」。
4. 安装完成后进入 **设置 → 插件中心**，确认插件已启用。
5. 首次挂载的插件需要先点击「配置菜单」，选择分类并创建左侧导航入口。

市场安装会下载 zip、校验完整性，并把插件解压到本机用户目录。客户端还会重新执行一次包校验，校验不通过会拒绝安装。

## 离线导入

没有登录账号或需要指定版本时，可以离线导入：

1. 获取插件 `.zip` 包。
2. 打开 **设置 → 插件中心**。
3. 点击「导入插件包」，选择 zip。
4. 安装成功后启用插件并配置菜单。

同名包重复导入会覆盖安装，并保留插件的私有存储。

## 安装位置

| 平台 | 路径 |
| --- | --- |
| Windows | `%APPDATA%\Prime Work\plugins\<插件名>\` |
| macOS | `~/Library/Application Support/Prime Work/plugins/<插件名>/` |

## 更新与卸载

- 市场检测到更高版本后，安装按钮会变为「更新」。
- 导入同名 zip 也可以覆盖升级，插件的私有存储会保留。
- 停用插件会隐藏入口，数据保留。
- 卸载会删除插件目录，插件配置与私有存储默认保留在本机。

## 限制

- 浏览器预览模式可以浏览市场，但不能安装。
- 从市场安装需要登录账号；离线导入不需要。
- 外部插件不能声明 `desktop` 权限。
- 市场插件运行在沙箱中，是否支持内嵌页面由插件自身能力决定。
