# 插件市场

插件市场用于安装、更新和管理外部插件。核心插件与内置插件随客户端交付，不通过市场安装；当前外部插件包括 SSH 终端、站点导航与页面菜单。

## 从市场安装

1. 登录云端账号。
2. 打开 **设置 → 插件市场**。
3. 选择插件并点击「安装」。
4. 安装完成后进入 **设置 → 插件中心**，确认插件已启用。
5. 插件清单声明了导航菜单时会自动创建入口，无需再手动「配置菜单」；只有未声明菜单的旧包才需要手动配置。

市场安装会下载 zip、校验完整性，并把插件解压到本机用户目录。宿主加载入口文件时还会校验 SHA-256，校验不通过会拒绝运行。

## 离线导入

没有登录账号或需要指定版本时，可以离线导入：

1. 获取插件 `.zip` 包。
2. 打开 **设置 → 插件中心**。
3. 点击「导入插件包」，选择 zip。
4. 安装成功后启用插件，声明了导航菜单的插件会自动出现入口。

同名包重复导入会覆盖安装，并保留插件的私有存储。通过本地调试服务导入的开发副本以 `<name>-dev` 安装，与正式包并存。

## 插件中心分组

插件中心按类型分组展示插件，开发中的插件置顶：

- 开发中：从本地调试服务导入的源码
- 全局插件：设置页承载的系统能力与配置入口
- 功能插件：提供独立页面的插件
- 面板插件：接管右侧面板的插件
- 工具插件：不提供界面，向 Agent 提供能力

卡片会展示来源（核心 / 内置 / 外部）、领域标签（工具、模型、UI 增强等）与客户端版本要求。

## 安装位置

| 平台 | 路径 |
| --- | --- |
| Windows | `%APPDATA%\Prime Work\plugins\<插件名>\` |
| macOS | `~/Library/Application Support/Prime Work/plugins/<插件名>/` |

## 更新与卸载

- 市场检测到更高版本后，安装按钮会变为「更新」。
- 导入同名 zip 也可以覆盖升级，插件的私有存储会保留。
- 停用插件会隐藏入口，数据保留。
- 卸载会删除插件目录；插件配置与私有存储默认保留在本机，可在 **设置 → 隐私与数据 → 本地数据** 中查看明细并手动清理。

## 限制

- 浏览器预览模式可以浏览市场，但不能安装；可以使用本地调试服务导入源码预览界面。
- 从市场安装需要登录账号；离线导入不需要。
- 外部插件不能声明 `desktop` 权限。
- 市场插件默认以 Shadow DOM 沙箱挂载，样式与宿主隔离；是否内嵌页面由插件自身能力决定。
