# 快速上手

Prime Work 把 SSH 终端、AI 助手、站点导航与插件收进同一个工作台。本指南从登录开始，带你完成第一个任务。

## 登录

Prime Work 使用飞书账号登录。打开应用后点击登录按钮，在飞书完成授权，回到应用即可。

登录后，菜单、分类、插件状态、站点导航、SSH 主机与 AI 会话会随账号同步；换一台设备登录也能恢复。

## 连接主机

在左侧打开 **SSH 终端**，点击「新增主机」，填写：

- 主机地址与端口
- 用户名
- 认证方式：密码、私钥或 ssh-agent

第一次连接时，应用会显示主机指纹，确认与服务器一致后再接受。连接成功后可以打开多标签会话、浏览 SFTP 文件或配置端口转发。

详细说明见 [SSH 终端](/docs/ssh)。

## 启用插件

打开 **设置 → 插件中心**，按需启用插件。首次启用会列出该插件申请的权限；停用插件会隐藏入口并断开相关能力，卸载会清理插件目录。

外部插件可以从开发目录、本地调试服务或 `.zip` 包导入。插件由宿主直接挂载并可选 Shadow DOM 沙箱，权限未声明即拒绝；声明了导航菜单的插件启用后会自动出现入口。

## 试试 AI 助手

在右侧打开 **AI 助手**：

1. 在设置 → 模型配置 中配置模型并测试连通性。
2. 在 Chat 模式提问，或切换到 Agent 模式让它执行多步任务。
3. Agent 执行终端命令前会请求确认。

输入 `/` 可以选择技能。更多说明见 [AI 助手](/docs/ai)。
