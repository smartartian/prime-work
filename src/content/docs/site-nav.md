# 站点导航

站点导航（`site-nav`）把常用站点按分组收纳，点击卡片后用系统浏览器打开。当前以外部插件形式分发。

## 安装

- **市场安装**：设置 → 插件市场 → 站点导航 → 安装。
- **离线导入**：设置 → 插件中心 → 导入插件包，选择 zip。
- 客户端要求以插件市场提示为准；新运行时需要较新的客户端版本。
- 首次安装后，在插件中心点击「配置菜单」，选择分类并创建左侧导航入口。

## 使用

1. 点击「新增站点」，填写名称、网址与分组。
2. 网址必须以 `http://` 或 `https://` 开头。
3. 站点按分组显示为卡片，左上角色块按域名自动生成。
4. 点击卡片名称或双击卡片，用系统默认浏览器打开。
5. 支持按名称或域名搜索。
6. 鼠标悬停卡片右上角「×」可以删除站点。

## 数据与权限

- 站点数据保存在插件私有存储的 `sites` 键下，与其他插件隔离。
- 数据只保存在本机，不随云端配置同步；换机需要重新录入。
- 权限：`storage`、`network`。
- 不申请 `filesystem`、`ssh`、`ai`、`desktop`，不能读取本地文件或执行命令。
- 链接使用系统浏览器打开，不在工作台内嵌渲染。

## 更新与卸载

- 市场更新或导入同名 zip 会覆盖安装，站点数据保留。
- 停用插件后入口不可用，数据保留。
- 卸载会删除插件目录，插件配置与私有存储默认保留。

## 常见问题

**安装后左侧没有入口？**

初次挂载的插件需要先配置菜单：插件中心 → 站点导航 → 配置菜单，选择分类并创建入口。

**提示 `main.js` 不存在？**

旧版插件包使用 `index.html` 入口，与新版宿主运行时（`main.js` + `window.__primePlugin.mount`）不兼容。请升级到市场中的最新版本。

**站点数据会同步吗？**

不会。站点数据只保存在本机插件存储中。
