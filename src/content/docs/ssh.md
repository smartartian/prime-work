# SSH 终端

SSH 终端（`ssh-terminal`）是 Prime Work 的上架插件，通过宿主 `pwb.ssh.*` 桥接完整 SSH 能力。插件注册「SSH 终端」与「主机配置」两个菜单。

## 安装与启用

- 打开 **设置 → 插件市场** 安装 SSH 终端；也可以在插件中心导入 zip 包。
- 当前版本 0.0.5，需要客户端 0.0.17+，具体以插件市场提示为准。
- 安装后在 **设置 → 插件中心** 启用，两个菜单会自动创建，无需手动配置。
- 插件权限：`ssh`、`storage`。

## 菜单与入口

- **SSH 终端**：位于左侧主导航的「终端与运维」分组。
- **主机配置**：位于 **设置 → 插件设置**，与终端共享同一份主机数据。

## 主机管理

新增主机时填写地址、端口、用户名和认证方式：

- **密码**：加密保存在本机与服务端
- **私钥**：选择本地私钥文件
- **ssh-agent**：使用系统代理中的密钥

主机列表按最近连接排序；终端页与 **设置 → 插件设置 → 主机配置** 共享同一份主机数据。

## 首次连接与指纹校验

第一次连接某台主机时，应用会显示服务器指纹（TOFU）。确认与服务器一致后再接受；指纹变化时会再次提示，避免连接到被替换的主机。

## 多标签会话

一个窗口可以打开多个会话标签，断线后可以重新连接。终端输出支持复制，选中的内容可以发送到 AI 助手作为上下文。

## SFTP 文件管理

连接后可以浏览远程目录、上传下载文件，并新建、重命名或删除文件。

## 端口转发

支持三种规则：

- 本地转发
- 远程转发
- 动态 SOCKS5

规则会持久化，并随会话启用。

## 会话日志

终端输出可以自动记录到本机，按主机回看与清理。日志摘要与完整日志的开关会随账号同步。

## 安全建议

- 使用密钥认证，并给私钥设置口令。
- 不要在不可信网络保存明文密码。
- 定期检查已知主机指纹。
- 只对信任的插件开放 `ssh` 相关能力。
