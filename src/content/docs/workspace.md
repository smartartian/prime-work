# 工作台与插件中心

Prime Work 的主界面由左侧导航、页面容器与右侧 AI 面板组成。插件、菜单与设置都围绕这套外壳展开。

## 左侧导航

- 工作台、站点导航、页面菜单、SSH 终端、AI 助手等入口
- 按分类组织，支持收藏、折叠与拖拽排序
- 菜单与分类随账号同步
- 安装、卸载插件后自动刷新

## 页面容器

- AI 页与外部插件页使用统一的描边、圆角与投影
- 外部插件由宿主直接加载 `main.js` 并挂载，可开启 Shadow DOM 沙箱隔离样式
- 是否支持内嵌页面由插件能力决定；市场版「页面菜单」使用系统浏览器打开

## 插件中心

打开 **设置 → 插件中心** 可以：

- 按类型查看插件：开发中置顶，其余按全局 / 功能 / 面板 / 工具分组
- 启用或停用插件；核心插件只读，不可停用或卸载
- 查看插件来源（核心 / 内置 / 外部）、领域标签、权限与客户端版本要求
- 导入 `.zip` 插件包、本地开发目录，或从本地调试服务导入源码
- 为未声明菜单的旧包手动配置菜单
- 卸载插件；插件私有数据默认保留，可在「设置 → 隐私与数据 → 本地数据」清理

停用插件会隐藏入口并断开相关能力，数据默认保留。声明了导航菜单的插件启用后会自动创建入口，声明 `section: settings` 的菜单会出现在「设置 → 插件设置」。

## 设置

设置中心包括：

- 账号、版本与更新
- 插件中心与插件市场
- 插件设置：由插件注册的设置页菜单组成，例如 SSH 主机配置
- 模型配置与连通性测试
- 外观、硬件加速与关于

## 搜索

工作台提供全局搜索入口，用于快速定位菜单、站点与插件。具体结果取决于当前启用的插件。
